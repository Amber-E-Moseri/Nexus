Clear Old Event Data

Only after TII2 is fully wrapped up
⚠

Irreversible. Export anything you need first. Verify the Registration page shows 0 records before proceeding with any other step.

Run in the Supabase SQL editor:

-- Clear the five registration tables
truncate table registrations  restart identity cascade;
truncate table roster          restart identity cascade;
truncate table working_list    restart identity cascade;
truncate table event_payments  restart identity cascade;

-- Clear config: targets, room assignments, public token
delete from registration_config;
4

Set Up the Google Sheet & Apps Script

Connects the source form to Nexus

Make a copy of the TII2 Google Sheet (or create a new one with the same column headers). Open Extensions → Apps Script. Paste the contents of src/features/registration/appScript.gs.

Script Properties

In Apps Script: Project Settings → Script Properties → Add property:

PropertyValue
NEXUS_API_URLhttps://blwcannexus.vercel.app/functions/v1/registrations-sync
NEXUS_API_KEYThe key from Step 5

Run onOpen() once to register the Nexus Sync custom menu. Test with Nexus Sync → Sync Working List to Nexus — should complete with no errors.

ℹ

If the new form uses different column headers, update HEADER_MAP in appScript.gs to match. Column matching is exact-string — check spelling carefully.

5

API Key — Set, Rotate, or Recover

Authenticates the Google Sheet → Nexus sync

First-time setup

supabase secrets set NEXUS_API_KEY=<generate-a-long-random-string>

If the key has expired or was rotated

# 1. Generate a new key with any secure random generator
# 2. Update the Supabase secret
supabase secrets set NEXUS_API_KEY=<new-key>

# 3. Update the Google Sheet: Extensions → Apps Script
#    Project Settings → Script Properties → NEXUS_API_KEY

# 4. Test: run "Sync Working List to Nexus" from the sheet menu

Verify what's set

supabase secrets list  # shows key names only, not values

If the edge function rejects all requests (401)

  • Check the Apps Script property — no trailing space, no quotes around the value
  • Re-deploy in case the secret wasn't picked up after rotation:
supabase functions deploy registration-api-sync
supabase functions deploy registrations-sync
6

Generate the Public Share Link

Read-only view — no emails or phone numbers exposed

Once data is loading correctly, go to /registration → Data tab → Public Share Link → click Generate link. Share the URL with whoever needs read-only access (subgroup leaders, exec team).

The link shows: name, subgroup, fellowship, registration status only.

To expire a token

Click Remove link in the Data tab. The old URL immediately returns empty results. Generate a new one if needed.

ℹ

If the token stops working, the get_public_registration_data RPC reads from registration_config where key = 'public_token'. If that row was deleted, regenerating from the UI recreates it.

Set Up Finance & Rooms Access

Granted per-user, independent of team membership 
-- Find a user's UUID
select id, name, email from users where name ilike '%Name%';

-- Grant finance tab access
insert into user_grants (user_id, grant_type, granted_by)
values ('<user-uuid>', 'finance_data_access', '<your-uuid>');

-- Grant room assignment tab access
insert into user_grants (user_id, grant_type, granted_by)
values ('<user-uuid>', 'rooms_access', '<your-uuid>');

-- Revoke when the event is done or person changes
delete from user_grants
where user_id = '<user-uuid>'
  and grant_type = 'finance_data_access';

Troubleshooting

"Access denied" on /registration ▸
The person isn't in any sprint team for this event. Add them to a team in the Nexus Sprint page.
Sync button does nothing / no data appears ▸

Check Apps Script properties — NEXUS_API_URL and NEXUS_API_KEY must both be set.

Run syncAllToNexus manually from Apps Script and read the execution log.

Confirm edge functions are deployed: supabase functions list

Rooms tab is missing ▸
User isn't a super_admin, regional_secretary, Programs space member, Accommodation team member, or rooms_access grant holder. Add them to the Accommodation sprint team or insert a user_grants row.
Public link returns an empty page ▸
Token was deleted or never generated. Go to Data tab → Generate link.
API sync returns 401 Unauthorized ▸
Rotate the API key — see Step 5.
Registrations not matching roster names ▸
The sync strips honorifics (Pastor, Sis, Bro, Dr) and normalises spacing before matching. If it still fails, check the roster full_name column for extra characters or encoding issues.
