5. CLASSIFICATION — EXACT PROVEN CAUSE
═══════════════════════════════════════════════════════════════════════════════

ROOT CAUSE: PostgreSQL Table Privilege Defect (Fresh-Install)

PostgreSQL error 42501 = "permission denied"
Supabase service_role lacks base table privileges on:
  - icplc_participants
  - icplc_import_rows
  - icplc_import_batches
  - event_configs
  - users

Migrations created these tables with RLS enabled, but did NOT grant 
SELECT/INSERT/UPDATE/DELETE to service_role.

This is NOT an RLS policy issue. It is a base table GRANT issue.

The hint from PostgreSQL is explicit:
  GRANT SELECT, INSERT ON public.icplc_participants TO service_role;
